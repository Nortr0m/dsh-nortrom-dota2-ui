# dsh-nortrom-dota2-ui

把 **DeepSeek Harness (DSH)** 的 Web 界面整体换装成 **Dota 2** 风格的 Cordis 插件。

> 主机端（Host）负责从你本机的 Dota 2 安装里**实时读取游戏资源**并做解码，
> 客户端（Client）负责渲染皮肤、卡片与开场动画。**素材不复制、不打包、随游戏更新自动生效。**

---

## 特性

### 界面与配色
- 天辉金 × 夜魇红的对峙配色，覆盖面板 / 边框 / 文字 / 侧栏
- **面板不透明度** 0.40–0.98 实时可调
- **配色跟随背景**：从当前壁纸抽取主色，面板、边框、强调色与 76 处金色系随之切换
- **纯净壁纸模式**：去掉壁纸上的渐变蒙版与暗角，让壁纸原样呈现

### 界面背景（1128 张，直接来自游戏）
- Host 运行时从 `pak01_*.vpk` 读取**载入画面**纹理，做 **BC3 / YCoCg-DXT5** 反变换，
      用 Node 内置 `zlib` 现场编码成 PNG 返回，带内存 LRU 缓存
  - **不复制、不占空间**：插件本体仅约 0.9 MB（3 张内置图 + logo）
  - 缩略图按块抽样生成（7–32 ms），原图约 120–140 ms
- **筛选查询**：关键词搜索 + 分类（通用/英雄套装/TI 主视觉/TI 珍藏/Artgerm/…）+ 英雄标签（按数量排序）
- 自动发现游戏安装目录：全盘符 × 常见安装位置 + 多处 `libraryfolders.vdf`

### 玩家卡片
- Steam 头像、玩家名、天梯段位（如「万古流芳 IV」）
- **近 20 局胜负**：MAX+ 风格**逐局英雄小格**，**仅统计天梯局**（`lobby_type = 7`），下方色条表示胜负
- **悬停显示该局 10 人详情**：双方各 5 人 —— 英雄头像、玩家名、K/D/A、**6 格装备 + 1 格中立物品**，你自己的那行高亮
- **战绩本地缓存**：Host 定时抓取并落盘到 `_cache/dota.json`，前端只读本地（零额度消耗）
  - 额度预算（OpenDota 免费 2000 次/天）：资料 30 分钟、列表 2 分钟、详情只为新对局抓 → **约 900 次/天**

### 开场动画
- **自制「白金徽记」动画**：六边形勋章 + 剑 + 符文，逐笔描边绘制 → 白金填充 → 高光扫过
- 下方依次浮现**近 3 个月最常玩的 3 个英雄**（头像 + 中文名 + 场次 + 胜率）
- 也可切换为游戏原版开场影片（自动跳过 Valve 标志与黑场），支持带声音播放

## 安装

```bash
# 1) 把本仓库放进 DSH 工作区（或任意位置）
# 2) 用 DSH 的 plugin_manager 安装本目录：
#    action=install_bundle  target=<本目录绝对路径>
```

安装后**需要重启 DSH**（Host 与 Client 两半都会加载；仅客户端改动刷新页面即可）。

依赖：DSH 的 **Web 界面** 插件（提供槽位与主题令牌）。**无任何第三方 npm 依赖。**

---

## 数据来源

| 用途 | 来源 |
|---|---|
| 载入画面 / 开场影片 / 模型 | 你本机的 Dota 2 安装（`pak01_*.vpk`） |
| 玩家战绩 / 英雄统计 | [OpenDota](https://www.opendota.com/) 公开 API |
| 英雄头像 / 物品图标 | Valve 官方 CDN（`cdn.cloudflare.steamstatic.com`） |

> 仓库内**不包含**任何游戏素材本体（仅有 3 张官方宣传图与项目 logo 用于离线兜底）。

## 配置

玩家账号 id 在 `client.js` 与 `index.js` 中（`PLAYER_ID` / `DOTA_PLAYER`），改成你自己的即可。
